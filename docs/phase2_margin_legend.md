# 第二期：融資融券註記與平盤下名單欄位（官方原文摘錄，2026-11-06 擷取）

## 櫃買 margin/balance「備註」欄
來源：https://www.tpex.org.tw/zh-tw/mainboard/trading/margin-trading/transactions.html 頁面說明
- 備註欄表示「成交日次一營業日」的股票融資融券狀況（註記在 D 日資料，適用 D+1）。
- 數字（1、2、3…）：合計降低融資比率、提高融券保證金成數
- O：停止融資　X：停止融券　@：融資分配　%：融券分配　!：停止買賣
- *：融券餘額占融資餘額 60% 以上
- A：股價波動過度劇烈　B：股權過度集中　C：成交量過度異常　D：監視第二次處置
- 說明未列的符號（例：$）→ 標「資料不足」，不自行解讀。
- 說明是現行版本；早年代碼含義是否相同未驗證。

## 平盤下得融（借）券賣出名單（證交所 TWT92U、櫃買 margin/mark）
- 欄位：證券代號、證券名稱、暫停融券賣出、暫停借券賣出、前一交易日收盤價跌停本日禁止平盤下融（借）券賣出；「*」表示有此限制。
- 證交所附註：名單只含得為融資融券交易的上市證券；不含未取得資格或依標準第四、五條暫停融資融券者。
- 實際下載結果：證交所名單自 2013-09-23、櫃買自 2013-09-18 起有資料（之前查詢只回空表或一列日期）。
- 變更交易：證交所 /rwd/zh/fullDelivery/TWT85U（每日名單，官方自 93/12/24 起）、/rwd/zh/fullDelivery/BFIHBU（新增之變更交易，頁面起始 2019）。

## 證交所 MI_MARGN「註記」欄（API 附註原文）
- 備註欄係表明成交日次一營業日股票融資融券狀況。
- 符號：O 停止融資、X 停止融券、@ 融資分配、% 融券分配、! 停止買賣。
- 附註為現行版本，隨歷史查詢一併回傳；早年含義是否相同未驗證。
- 櫃買早年另有「$」（2007-06～2011-01）、「E」（2012-03）不在說明內 → 資料不足；「,」視為分隔符。
